# Disposable feasibility probes

Run from the repository root. Build outputs stay under ignored `build/unified-p0`; never use real credentials or personal browser profiles. The probes do not install a production app, enable browser extensions, or grant OS consent. Current results and unfinished gates: [P0 evidence](../../../docs/unified/P0_BASELINE.md).

- `python3 scripts/unified/p0/build-macos-probe.py` compiles and ad-hoc signs the Apple Silicon probe. `build/unified-p0/mac-probe capabilities` reads hardware support; `restore-info` retrieves Apple restore metadata. The tool sandbox can prevent Virtualization XPC access; use the authorized development environment.
- `python3 scripts/unified/p0/fetch-restore.py` fetches the pinned Apple image with resume, size, digest, and free-space checks. This is about 25 GiB. Do not run until there is space for **both** the image and the guest installation. The installer separately requires 64 GiB available for important usage and 16 GiB immediately free after the download. The available estimate includes space macOS can reclaim automatically; it is not a reservation. Installation still cancels below 8 GiB immediately free. These are development reserves, not production minimums.
- `build/unified-p0/mac-probe install` creates a new disposable guest with no NIC or host share. It refuses an existing workspace and stops installation below the free-space reserve. `lifecycle` requires a completed installation and exercises start/pause/resume/cold restart. It does not claim desktop verification.
- `python3 scripts/unified/p0/probe-encrypted-workspace.py` exercises an encrypted disk image with a memory-only random key and synthetic data. No Keychain or vault integration. It unmounts the test image when finished.
- `python3 scripts/unified/p0/test-native-messaging.py` checks the bounded echo-only host protocol with actual child processes. It is not a browser integration test.
- `python3 scripts/unified/p0/build-safari-probe.py` generates and compiles the Safari app-extension fixture without signing credentials or installation. The missing-icon packager warning is expected for this fixture. Browser invocation still requires an isolated guest and supported extension enablement.

The extension accepts only an explicitly marked loopback synthetic page at `/josi-p0-fixture`, and returns only its title and button count. No production control path exists. Firefox needs its explicit extension ID and native manifest registration; Chrome/Brave need exact native-host allowed origins; Safari uses its own native handler. Do not register these fixtures against a personal browser profile.

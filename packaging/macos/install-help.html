Josi CE Server on Apple Silicon

Use Josi CE Server Setup.app on an Apple Silicon Mac running macOS 14 or later. Open the app, choose Install Josi CE Server, and approve the Mac administrator prompt.

Installation may take several minutes. Keep the setup window open. It shows the current phase and service, a moving activity indicator, and elapsed time while preparing the database and starting Josi.

When ready, setup opens your default web browser. Complete ownership and recovery setup there. Keep the recovery key somewhere private. You can return using Open Josi in the setup app or http://localhost:8080/.

Private by default

The server listens only on this Mac. It does not require Docker, a virtual machine, Homebrew or a separately installed developer runtime. An existing installation is preserved; an upgrade verifies a private snapshot and applies database migrations before starting the new version.

Documents and speech

No malware scanner is bundled. Document uploads, indexing and OCR remain blocked until an administrator explicitly configures a supported local scanner and verifies its health. Disabling a legacy scanning setting does not bypass this requirement. Admin Storage shows the current scanner status.

CPU speech engines and their models are included and work offline. Microphone access still requires permission from your browser and macOS.

Verify and recover

The setup app includes TEST-ME with all six service labels, a status command, expected local ports, and separate clean-install and upgrade checklists. If setup stops, preserve its transaction evidence and existing data. Do not erase an older installation or recovery keys to retry.

This acceptance candidate still requires SOCAL signing and separate physical acceptance. A successful isolated package test does not establish a clean install, upgrade, reboot, microphone or speaker result.

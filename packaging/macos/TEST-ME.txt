ONE-STEP INSTALLER (AFTER SEPARATE SIGNING/PHYSICAL TEST AUTHORIZATION)
Double-click Josi CE Server Setup.app and choose Install Josi CE Server. Approve
macOS administrator authorization. Installation may take several minutes. The
spinner/elapsed counter must keep moving, with current phase/service displayed.
Open Josi hands setup to the default HTTP browser through a private one-use link.
Verify package requires no elevation and installs/starts nothing.

"/path/to/Josi CE Server Setup.app/Contents/MacOS/josi-native-status"
Reports every label, expected startup, running state and PID. Exit 1 means a
required job is absent/not running; exit 2 means inspection failed. A PID alone
is not health. Also run:
  /usr/bin/curl --fail --max-time 5 http://localhost:8080/ready
One job: /bin/launchctl print system/com.heyjosi.ce.web
Do not share raw launchctl output, private logs or transaction directories.
Build-host observation: all six labels are NOT REGISTERED; live service health
is not applicable. This run exercised isolated child processes only.

SCANNER POLICY — NO CLAMAV ENGINE, DEFINITIONS OR UPDATER IS BUNDLED
The supported adapter uses PING and INSTREAM over an administrator-configured
clamd-compatible Unix socket. Josi installs no scanner service/account/listener.
An empty configuration blocks ingestion. PING establishes availability only;
each exact document stream requires a clean verdict. Errors, timeouts, malformed
replies, absent engines and malware detections fail closed.
An administrator may set scannerSocket in the root-owned 0644 file:
  /Library/Application Support/Josi CE Server/data/config/runtime.json
Use a canonical absolute root-owned socket with no access for others. All parent
directories must be root-owned and not group/world writable. Neither socket nor
parents may have extended ACLs. Give web/worker access through a dedicated scanner
group, never by broadening either primary service group. Restart those two jobs
after group changes. Verify Admin Storage health, a harmless document and an
approved scanner test signature. External scanner configuration/acceptance has
not been performed. No Homebrew runtime is required by this package.

Use a separately authorized disposable Mac with no existing product root, labels

UPGRADE — SEPARATE PHYSICAL PROCEDURE, NOT PERFORMED HERE
Start with a separately accepted native macOS baseline of a different version
and representative users, documents, conversations, settings and credentials.
Make an independently verified private backup. Run the newer installer. Confirm
quiescence, verified cold snapshot, migrations-before-writers and preserved data.
Compare login/data behavior, reboot, then repeat the checklist. Same-version
installation is refused. PostgreSQL major-version conversion is not implicit;
this candidate uses major 16. Isolated child-process upgrade tests are not this
physical upgrade procedure and do not authorize changing an existing installation.

RECOVERY
Private data, keys and logs: /Library/Application Support/Josi CE Server/data.
Immutable journals/cold snapshots: transactions in that product root. Programs:
versions/<version>. Never remove failed data, snapshots, identities, keys, old
programs or incomplete journals. Before migration, recovery restarts the intact
previous installation. After migration but before activation, it verifies the
cold snapshot, retains failed data, then restores the previous version. Once
activation begins, automatic rollback is refused to protect newer writes; preserve
everything for lossless review. Fresh partial provisioning is retained for review.
The fixed root-only helper supports `recover <32-hex transaction ID>`, using the
trusted installed private Python (-I -B) and app/native/lifecycle.py. Review the
transaction first; never elevate a helper from an untrusted download.

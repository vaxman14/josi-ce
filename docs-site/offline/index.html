Help and current features

Josi CE provides one self-hosted workspace with conversations, tasks, approvals, contacts, memory, model providers, connected accounts, operational mail, documents, external messaging channels, backups, diagnostics, an installable web app, optional Voice Box, and integrations.

Administrators configure the installation under Admin. Members use their own accounts under Workspace.

First-run recovery key

The setup wizard shows the recovery key once. Select Copy key or Download key, store it away from the Josi computer, and then confirm that it was saved. There is no separate terminal command for this step.

Backups and system checkup

Admin → Overview shows installation status and recommendations. Admin → Backups creates backups and configures SMB or NFS storage. Keep the recovery key separately from the backup destination.

Integrations

Admin → Integrations connects model providers and external services. Credentials stay in the Master Vault. Consequential writes and deletes still require approval.

Family / Parental Controls BETA

Do not rely on these controls for a child's safety. They control only access to Josi. They do not lock a device, block other apps or websites, monitor location or actual screen time, contact emergency services, or replace active adult supervision and proven device-level controls.

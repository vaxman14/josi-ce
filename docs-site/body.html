Josi CE Help

Install Josi with Docker, finish setup in your browser, and manage the normal day-to-day work inside Josi.

Help and current features

Josi CE provides one self-hosted workspace with conversations, tasks, approvals, contacts, memory, model providers, connected accounts, operational mail, documents, external messaging channels, backups, diagnostics, an installable web app, optional Voice Box, and integrations.

Administrators configure the installation under Admin. Members use their own accounts under Workspace.

First-run recovery key

The setup wizard shows the recovery key once. Select Copy key or Download key, store it away from the Josi computer, and then confirm that it was saved. There is no separate terminal command for this step.

Backups and system checkup

Admin → Overview shows installation status and recommendations. Admin → System checkup runs Josi Doctor. It explains problems, offers only bounded automatic repairs, asks for approval, and verifies the result. Admin → Backups creates backups and configures SMB or NFS storage. Keep the recovery key separately from the backup destination.

Integrations

Admin → Integrations connects model providers and external services. Credentials stay in the Master Vault. Consequential writes and deletes still require approval.

Family / Parental Controls BETA

Do not rely on these controls for a child's safety. They control only access to Josi. They do not lock a device, block other apps or websites, monitor location or actual screen time, contact emergency services, or replace active adult supervision and proven device-level controls.

1. Run the installer

Install and open Docker first. You do not need Git, Node.js, a source checkout, or a Josi command-line tool.

Choose the command for your computer and paste the whole block into Terminal.

Mac

mkdir -p "$HOME/josi-ce" && cd "$HOME/josi-ce" && \
docker run --rm \
  -p 8080:8080 \
  -v "$HOME/.docker/run/docker.sock:/var/run/docker.sock" \
  -v "$PWD:$PWD" -w "$PWD" \
  docker.io/romanvaxman/josi-ce-installer:latest

Linux

mkdir -p "$HOME/josi-ce" && cd "$HOME/josi-ce" && \
docker run --rm \
  -p 8080:8080 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v "$PWD:$PWD" -w "$PWD" \
  docker.io/romanvaxman/josi-ce-installer:latest

The installer prints a private setup URL and a one-time setup code. Leave the Terminal window open while setup is running.

The temporary installer can control Docker so it can create the Josi services. It exits when installation finishes. Normal Josi services do not receive the Docker socket.

2. Finish setup in your browser

  1. Open the setup URL printed in Terminal.
  2. Accept the temporary local-certificate warning.
  3. Enter the one-time setup code.
  4. Choose whether Josi is available on this computer, your local network, a public domain, or through an existing proxy or tunnel.
  5. Optionally choose one project folder for coding features. Skip it if you do not need Josi to work with local files.
  6. Review the choices and select Install Josi.

The browser installer writes the configuration, generates the installation secrets, downloads the published images, starts Josi, and checks that it opens.

3. Open Josi

When installation succeeds, select Open Josi. The first person through setup becomes the administrator.

Josi walks through the account, AI provider, privacy choices, and optional connections. When the recovery key appears, copy or download it and store it somewhere other than the Josi computer.

4. Confirm it works

Open the Josi URL and send a message. If Josi opens and answers using the provider configured during setup, the installation works. You do not need to inspect containers or call health endpoints.

After installation

Use Josi's Admin screens for normal management:

  • Overview shows status and recommendations.
  • System checkup explains problems and offers safe automatic repairs for approval.
  • Network & address changes local, LAN, domain, proxy, or tunnel access.
  • Backups creates backups and configures storage.
  • Integrations connects providers and services.
  • Users manages workspace access.

Keep Docker running. On a dedicated Mac mini, enable Docker Desktop at login so Josi returns after a restart.

Use Josi on your devices

Your Josi server is the home for every client. The web app and native apps use the same account, workspace, conversations, memory, and tools.

  • Android: Install Josi CE from Google Play.
  • iPhone and iPad: The App Store release is coming soon.
  • macOS, Windows, and Linux: Desktop downloads are in final device testing. Links will appear here when each build is approved.

To connect a native app:

  1. Open Josi CE.
  2. Choose Public URL or Tailscale.
  3. Paste the Josi URL shown during server setup.
  4. Select Verify and continue.
  5. Sign in with the same Josi account you created in the browser.

The app connects to the Josi server you just installed. It does not install or create another server.

Updating Josi

Run the same installer command again. The browser installer detects the existing installation, preserves its configuration, and applies the published update. Do not delete the josi-ce folder or Docker volumes during an update.

Backups

Open Admin → Backups to create a backup or configure SMB/NFS storage. Keep the recovery key separately from the backup destination. A backup and the key protect different things, so you need both.

Troubleshooting

Docker is not running

Open Docker Desktop on Mac, or start Docker Engine on Linux, then run the same installer command again.

The Mac reports that the Docker socket does not exist

Wait until Docker Desktop says the engine is running, then retry. Josi uses Docker Desktop's user socket at $HOME/.docker/run/docker.sock.

Port 8080 is already in use

Stop the program using port 8080, then run the installer again. That port is used only for the temporary setup page.

The browser warns that the setup page is not private

This is expected for the temporary local setup certificate. Confirm that the address matches the one printed by the installer before continuing.

Setup was interrupted

Run the same installer command again. It reuses the $HOME/josi-ce directory and preserves completed configuration.

Josi installed but does not open

Return to the installer window and use its reported error. If Josi previously worked, open Admin → Overview for the system checkup. Do not delete Docker volumes or the installation directory while troubleshooting.

Description
Josi Browser Control connects your browser to Josi, the assistant app on your computer, so Josi can do things on the web for you.

Ask in Josi's chat and it happens in your browser:
• "What's on this page?": Josi reads the tab you are looking at.
• "Open mercari.com": Josi opens it in a new tab, and starts your browser if it is closed.
• "Describe each photo": Josi looks at pictures on the page, one at a time.
• Fill in fields, choose options, click, scroll, download and upload files, when you allow it.

You stay in charge:
• Every site and action follows the permissions you set in Josi's PC Control, or Josi asks you in chat first.
• It never reads or fills passwords, payment details or one-time codes.
• "Take control" in the popup stops Josi in this browser at once; Pause and Stop in Josi stop everything.
• No servers of its own and no ads. Page content goes only to the Josi app on your computer, which you run.

Requires the Josi app (heyjosi.com) installed and open on the same computer. Works in Chrome, Edge, Brave and Firefox.

Privacy tab

Single purpose
Lets the Josi assistant app on the same computer read and act on web pages in this browser when the user asks, within the user's Josi permissions.
nativeMessaging
Talks to the Josi app on the same computer; nothing else.
tabs
Knows which tab the user is looking at, and the site and title of open tabs so the user can say "go to my Gmail tab" in Josi.
activeTab
Acts on the tab the user is looking at when they ask Josi.
scripting
Reads the page and performs the requested action (fill, click, choose, scroll, upload) in the tab Josi uses.
storage
Remembers this browser's random id and, until the browser closes, which tab Josi is using.
alarms
Reconnects to the Josi app every 30 seconds while the browser is open, so it works again after Josi restarts.
downloads
Saves a file from the site in use into the Downloads folder when the user asks Josi and allows it.
Host permission
Josi opens or reads whichever site the user names in chat; asking per site at install time is not possible for sites named later. Every site and action is still allowed or approved by the user in Josi before anything is read or done.
